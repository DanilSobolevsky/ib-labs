# Шаг 4. Отчёт об инциденте (около 15 минут)

Напишите отчёт из пяти пунктов (по 1–3 предложения) и отправьте его в Stepik. Здесь отчёт писать не нужно.

1. **Что произошло.** Хронология с временем.
2. **Какие свойства нарушены** и почему.
3. **Цепочка атаки.** Шаги и тактики ATT&CK.
4. **Оценка риска (учебная).** Вероятность × ущерб по шкале 1–5.
5. **Три меры защиты.** Для каждой укажите, что она предотвращает или обнаруживает, её класс и функцию, какой принцип защиты она восстанавливает.

**Оценка в Stepik (10 баллов, зачёт от 7):** хронология с временем — 2; нарушенные свойства с обоснованием — 2; цепочка с тактиками — 2; три меры с классом, функцией и принципом — 3; ясность и связь выводов с данными — 1.

После отправки в Stepik вы увидите эталонный отчёт для самопроверки.
