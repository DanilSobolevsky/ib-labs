# Шаг 3. Журнал входов на сервер (около 30 минут)

`auth.log` — фрагмент журнала сервера магазина за 11–12 октября. Слово `Accepted` означает, что вход удался, `Failed password` — что пароль неверный. В строках со словом `sudo` записаны команды, выполненные с правами администратора. В строках входов 9-е слово — имя пользователя, 11-е — IP-адрес.

Посмотрите журнал:

```bash
cat ~/lab1/auth.log
```{{exec}}

**Полезные команды**

Все неудачные попытки (`grep -c` вместо `grep` выводит только их число):

```bash
grep 'Failed password' ~/lab1/auth.log
```{{exec}}

Все строки с адресом 203.0.113.45 (`-F` ищет текст буквально):

```bash
grep -F 203.0.113.45 ~/lab1/auth.log
```{{exec}}

Сколько раз встречается каждое имя пользователя среди неудачных попыток:

```bash
grep 'Failed password' ~/lab1/auth.log | awk '{print $9}' | sort | uniq -c | sort -rn
```{{exec}}

Команды администратора:

```bash
grep sudo ~/lab1/auth.log
```{{exec}}
