# Шаг 2. Реестр активов магазина (около 15 минут)

Компания «Тюльпан»: интернет-магазин цветов, 12 сотрудников. Файл `assets.csv` — её реестр активов. Колонки: номер, название, тип, владелец, критичность, дата последнего пересмотра (через запятую).

Посмотрите файл целиком:

```bash
cat ~/lab1/assets.csv
```{{exec}}

**Полезные команды**

Сколько активов каждой критичности (`-F,` — разделитель запятая, `NR>1` — пропустить заголовок, `$5` — пятая колонка):

```bash
awk -F, 'NR>1 {print $5}' ~/lab1/assets.csv | sort | uniq -c
```{{exec}}

Строки, где четвёртая колонка (владелец) пуста:

```bash
awk -F, 'NR>1 && length($4)==0' ~/lab1/assets.csv
```{{exec}}

Чтобы посчитать строки, добавьте в конец команды `| wc -l`. Год пересмотра — первые четыре символа шестой колонки: `substr($6,1,4)`.
