КАК ПУБЛИКОВАТЬ СЦЕНАРИЙ lab1 НА KILLERCODA

1. Создайте публичный репозиторий на GitHub и загрузите в него папку lab1 целиком (index.json должен лежать в lab1/).
2. Войдите на killercoda.com и добавьте репозиторий на странице killercoda.com/creator/repository.
3. Откройте сценарий: killercoda.com/ВАШ-ЛОГИН/scenario/lab1.
4. Пройдите его с нуля, засеките время, сверьте числа с ключом (17, 15, 7, 02:14:41, admin, support2, export.tgz).
5. Вставьте ссылку в шаг 0 лабораторной в Stepik и оставьте запасной вариант.

[ПРОВЕРИТЬ по документации killercoda.com/creators] формат index.json (ключи intro.background, steps.verify, backend.imageid), синтаксис {{exec}}, имя образа ubuntu, лимит времени сессии бесплатного плана, доступность из вашей страны.
Ответов и эталонного отчёта в сценарии нет: они хранятся в Stepik.
