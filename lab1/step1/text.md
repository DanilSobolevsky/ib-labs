# Шаг 1. Проверка среды

Среда создала для вас папку `lab1` с двумя файлами: реестр активов `assets.csv` и журнал входов `auth.log`. Проверьте, что они на месте:

```bash
ls -l ~/lab1
```{{exec}}

```bash
wc -l ~/lab1/assets.csv ~/lab1/auth.log
```{{exec}}

**Критерий успеха:** в папке два файла, в `assets.csv` 13 строк, в `auth.log` 29 строк.

Если файлов нет, вставьте в терминал блок подготовки из шага 0 лабораторной в Stepik и повторите проверку.
